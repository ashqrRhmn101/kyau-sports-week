# University Sports Week — ফুটবল প্ল্যাটফর্ম

Next.js 14 + Supabase দিয়ে বানানো ইউনিভার্সিটি স্পোর্টস উইক ফুটবল টুর্নামেন্ট প্ল্যাটফর্ম।
প্লেয়ার, টিম, কোচ, ম্যাচ, লাইভ ইভেন্ট, লিডারবোর্ড এবং প্লেয়ার প্রোফাইল অ্যাপ্রুভাল ওয়ার্কফ্লো — সব একসাথে।

সম্পূর্ণ প্রজেক্টটা ফ্রি টিয়ারে চালানোর জন্য বানানো: **Vercel** (হোস্টিং) + **Supabase** (ডেটাবেজ + অথ + রিয়েল-টাইম)।

---

## ধাপ ১ — প্রয়োজনীয় জিনিস ইনস্টল করা

- [Node.js](https://nodejs.org) (ভার্সন ১৮ বা তার বেশি) — না থাকলে ইনস্টল করুন
- একটা কোড এডিটর (VS Code রেকমেন্ডেড)
- একটা [GitHub](https://github.com) অ্যাকাউন্ট (Vercel-এ ডিপ্লয় করার জন্য লাগবে)

চেক করুন Node.js ইনস্টল আছে কিনা, টার্মিনালে লিখুন:
```bash
node -v
```

---

## ধাপ ২ — Supabase প্রজেক্ট তৈরি করা (ব্যাকএন্ড, সম্পূর্ণ ফ্রি)

1. [supabase.com](https://supabase.com) এ যান, GitHub দিয়ে সাইন আপ করুন
2. **"New Project"** ক্লিক করুন
   - নাম দিন (যেমন `sports-week`)
   - একটা ডেটাবেজ পাসওয়ার্ড সেট করুন (এটা কোথাও সেভ রাখুন)
   - রিজিয়ন হিসেবে যেটা আপনার কাছের (Singapore) সেটা বাছুন
3. প্রজেক্ট তৈরি হতে ১-২ মিনিট লাগবে

### স্কিমা রান করা
1. বাম পাশের মেনু থেকে **SQL Editor** এ যান
2. **"New query"** ক্লিক করুন
3. এই প্রজেক্টের `supabase/schema.sql` ফাইলের সম্পূর্ণ কনটেন্ট কপি করে পেস্ট করুন
4. **"Run"** ক্লিক করুন — এটা সব টেবিল, ভিউ এবং সিকিউরিটি পলিসি তৈরি করে দেবে

### API কী নেওয়া
1. বাম মেনু থেকে **Project Settings → API** এ যান
2. দুইটা ভ্যালু কপি করুন:
   - **Project URL**
   - **anon public** কী

---

## ধাপ ৩ — প্রজেক্ট সেটআপ (নিজের কম্পিউটারে)

1. এই জিপ ফাইলটা আনজিপ করুন এবং টার্মিনালে সেই ফোল্ডারে যান:
```bash
cd sportsweek-app
```

2. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

3. `.env.local.example` ফাইলটার একটা কপি বানিয়ে নাম দিন `.env.local`, তারপর ধাপ ২-এ পাওয়া ভ্যালু দুইটা বসান:
```bash
cp .env.local.example .env.local
```
```
NEXT_PUBLIC_SUPABASE_URL=আপনার-প্রজেক্ট-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=আপনার-anon-key
```

4. ডেভ সার্ভার চালু করুন:
```bash
npm run dev
```

5. ব্রাউজারে যান: [http://localhost:3000](http://localhost:3000)

## ধাপ ৪ — নিজেকে অ্যাডমিন বানানো

1. সাইটে গিয়ে **"লগইন" → "সাইন আপ"** থেকে একটা অ্যাকাউন্ট খুলুন (নিজের ইমেইল দিয়ে)
2. Supabase Dashboard-এ ফিরে যান → **SQL Editor** → নতুন query
3. এই কমান্ড রান করুন (নিজের ইমেইল বসিয়ে):
```sql
update profiles set role = 'admin' where email = 'আপনার-ইমেইল@example.com';
```
4. সাইটে রিফ্রেশ দিলে এখন নেভবারে **"অ্যাডমিন"** লিংক দেখতে পাবেন

## ধাপ ৫ — শুরুর ডেটা যোগ করা (সিজন, কোচ, টিম)

প্রথম দিকে সিজন/কোচ/টিম তৈরি করার জন্য কোনো UI ফর্ম নেই (ইচ্ছাকৃতভাবে বাদ রাখা হয়েছে যাতে প্রজেক্ট সহজ থাকে) — Supabase-এর **Table Editor** থেকে সরাসরি এন্ট্রি করুন:

1. Supabase Dashboard → **Table Editor**
2. `seasons` টেবিলে একটা রো যোগ করুন (যেমন: `year: 2026`, `term: Spring`, `name: Spring 2026`)
3. `coaches` টেবিলে কোচদের তথ্য যোগ করুন
4. `teams` টেবিলে টিম যোগ করুন (department, season_id, coach_id বসিয়ে)
5. প্লেয়ার অ্যাপ্রুভ হওয়ার পর `team_players` টেবিলে `team_id` + `player_id` যোগ করে স্কোয়াডে রাখুন

চাইলে পরে আমাকে বলবেন — এই কাজগুলোর জন্যও একটা অ্যাডমিন UI ফর্ম বানিয়ে দিতে পারি।

## ধাপ ৬ — Vercel-এ ডিপ্লয় (লাইভ ওয়েবসাইট, ফ্রি)

1. এই প্রজেক্টটা একটা নতুন GitHub রিপোজিটরিতে পুশ করুন:
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/আপনার-ইউজারনেম/sports-week.git
git push -u origin main
```

2. [vercel.com](https://vercel.com) এ GitHub দিয়ে সাইন আপ করুন
3. **"Add New Project"** → আপনার রিপোজিটরি সিলেক্ট করুন → **Import**
4. **Environment Variables** সেকশনে `.env.local`-এর দুইটা ভ্যালু যোগ করুন
5. **"Deploy"** ক্লিক করুন — ২-৩ মিনিটে লাইভ হয়ে যাবে, একটা `.vercel.app` লিংক পাবেন

## প্রজেক্ট স্ট্রাকচার সংক্ষেপে

```
src/app/            → পেজগুলো (Next.js App Router)
  players/           → প্লেয়ার লিস্ট, প্রোফাইল, নতুন প্রোফাইল সাবমিশন
  teams/              → টিম লিস্ট ও ডিটেইল (স্কোয়াড, কোচ)
  matches/            → ম্যাচ লিস্ট ও লাইভ ডিটেইল পেজ
  leaderboard/        → টপ স্কোরার/অ্যাসিস্ট/রেটিং/কার্ড
  admin/              → অ্যাডমিন-অনলি: ড্যাশবোর্ড, প্রোফাইল অ্যাপ্রুভাল, ম্যাচ এন্ট্রি
  login/              → সাইন ইন/সাইন আপ
src/components/     → পুনঃব্যবহারযোগ্য UI কম্পোনেন্ট
src/lib/supabase/   → Supabase ক্লায়েন্ট সেটআপ
supabase/schema.sql → সম্পূর্ণ ডেটাবেজ স্কিমা + সিকিউরিটি পলিসি
```

## পারমিশন সিস্টেম কীভাবে কাজ করে

- **admin**: সব ডেটা এডিট করতে পারে, প্লেয়ার প্রোফাইল অ্যাপ্রুভ/রিজেক্ট করতে পারে, ম্যাচ এন্ট্রি করতে পারে
- **player**: নিজের প্রোফাইল সাবমিট করতে পারে — এটা `pending` অবস্থায় থাকে যতক্ষণ না অ্যাডমিন অ্যাপ্রুভ করে
- **viewer** (লগইন ছাড়া যে কেউ): শুধু অ্যাপ্রুভড ডেটা দেখতে পারে

এই পুরো নিয়মটা অ্যাপের কোডে না, বরং সরাসরি Supabase-এর **Row Level Security**-তে বসানো আছে
(`supabase/schema.sql` ফাইলে), তাই কেউ চাইলেও API সরাসরি কল করে বাইপাস করতে পারবে না।

## পরবর্তীতে কী যোগ করা যায়

- সিজন/কোচ/টিম তৈরির অ্যাডমিন UI ফর্ম
- MVP ভোটিং সিস্টেম
- ম্যাচ শেয়ার কার্ড (ইমেজ জেনারেট করে সোশ্যাল মিডিয়ায় শেয়ার)
- প্লেয়ার ফর্ম গ্রাফ (গত ৫ ম্যাচের রেটিং ট্রেন্ড)

নতুন কোনো ফিচার লাগলে বা কোথাও আটকে গেলে আমাকে জানাবেন।
