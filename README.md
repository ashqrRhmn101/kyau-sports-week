# University Sports Week — ফুটবল প্ল্যাটফর্ম

Next.js 14 + Supabase দিয়ে বানানো ইউনিভার্সিটি স্পোর্টস উইক ফুটবল টুর্নামেন্ট প্ল্যাটফর্ম।
প্লেয়ার, টিম, কোচ, ম্যাচ, লাইভ ইভেন্ট, লিডারবোর্ড এবং প্লেয়ার প্রোফাইল অ্যাপ্রুভাল ওয়ার্কফ্লো — সব একসাথে।


## প্রজেক্ট স্ট্রাকচার সংক্ষেপে

```
src/app/            → পেজগুলো (Next.js App Router)
  players/           → প্লেয়ার লিস্ট, প্রোফাইল, নতুন প্রোফাইল সাবমিশন
  teams/              → টিম লিস্ট ও ডিটেইল (স্কোয়াড, কোচ)
  matches/            → ম্যাচ লিস্ট ও লাইভ ডিটেইল পেজ
  leaderboard/        → টপ স্কোরার/অ্যাসিস্ট/রেটিং/কার্ড
  admin/              → অ্যাডমিন-অনলি: ড্যাশবোর্ড, প্রোফাইল অ্যাপ্রুভাল, ম্যাচ এন্ট্রি
  login/              → সাইন ইন/সাইন আপ
src/components/     → পুনঃব্যবহারযোগ্য UI কম্পোনেন্ট
src/lib/supabase/   → Supabase ক্লায়েন্ট সেটআপ
supabase/schema.sql → সম্পূর্ণ ডেটাবেজ স্কিমা + সিকিউরিটি পলিসি
```

## পারমিশন সিস্টেম কীভাবে কাজ করে

- **admin**: সব ডেটা এডিট করতে পারে, প্লেয়ার প্রোফাইল অ্যাপ্রুভ/রিজেক্ট করতে পারে, ম্যাচ এন্ট্রি করতে পারে
- **player**: নিজের প্রোফাইল সাবমিট করতে পারে — এটা `pending` অবস্থায় থাকে যতক্ষণ না অ্যাডমিন অ্যাপ্রুভ করে
- **viewer** (লগইন ছাড়া যে কেউ): শুধু অ্যাপ্রুভড ডেটা দেখতে পারে

এই পুরো নিয়মটা অ্যাপের কোডে না, বরং সরাসরি Supabase-এর **Row Level Security**-তে বসানো আছে
(`supabase/schema.sql` ফাইলে), তাই কেউ চাইলেও API সরাসরি কল করে বাইপাস করতে পারবে না।

## পরবর্তীতে কী যোগ করা যায়

- সিজন/কোচ/টিম তৈরির অ্যাডমিন UI ফর্ম
- MVP ভোটিং সিস্টেম
- ম্যাচ শেয়ার কার্ড (ইমেজ জেনারেট করে সোশ্যাল মিডিয়ায় শেয়ার)
- প্লেয়ার ফর্ম গ্রাফ (গত ৫ ম্যাচের রেটিং ট্রেন্ড)

নতুন কোনো ফিচার লাগলে বা কোথাও আটকে গেলে আমাকে জানাবেন।
